# Source-Bound Brand / Identity System Template Pack

`visual.brand.core` is the reusable identity-system foundation for games, software, studios, products and public-facing AXM surfaces.

A visual application or mockup is never canonical identity by itself. The canonical source remains the exact identity assets, rules, tokens, variants and provenance records.

## Surfaces

- project / identity hub
- marks and lockups editor
- typography editor
- icon-family editor
- identity-token editor
- clearspace / usage-rule editor
- identity-variant editor
- brand application editor
- review / rule audit
- export matrix

## Source-truth contract

- `brand-asset-source` — exact mark/logo/wordmark source, version, digest and provenance/rights state;
- `brand-lockup` — exact asset references, relative layout/spacing and approved-use identity;
- `brand-type-role` — exact font family/style/source plus semantic role;
- `brand-icon-family` — family identity/source/version, member references and construction rules;
- `brand-token` — exact value, unit/context, source and usage role;
- `brand-clearspace-rule` — exact mark/lockup target and measurement basis;
- `brand-usage-rule` — exact subject, context, allowed/forbidden/conditional status and source;
- `brand-application` — derived application bound to exact assets/tokens and target surface;
- `brand-variant` — exact base identity, deltas, intended context and availability;
- `brand-export-target` — exact asset/token/rule/format/provenance requirements.

## Truth boundary

A polished mockup is not proof that a logo, font, icon or palette is canonical. Visual similarity does not merge two identity assets. Spacing and clearspace rules require explicit measurement basis. Exceptions and restricted variants remain explicit. External rights or trademark validity are not inferred from repository provenance metadata.

This pack proves deterministic structural/editability contracts only. It does not by itself prove trademark clearance, font licensing, accessibility acceptance, market effectiveness, visual quality or legal rights.
