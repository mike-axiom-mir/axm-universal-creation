# Browser arena use loop — Signal Keep

This is a bounded use-and-improve pass on the existing offline arena generator.
The demo is generated through `UniversalCreationMachine.create`, not authored as
a separate replacement game. Its existing dependencies compile the session graph,
generate the PNG/WAV assets, publish mixed source/media, and validate exact files.

## Reproduce

```bash
PYTHONPATH=src python -m axm_uc create examples/requests/create_signal_keep.json
```

Open `creations/signal-keep/index.html` in a modern browser. For a repeat build,
explicitly choose `inputs.replace: true` in your request copy. No service or AI is
needed. The private hosted demonstration is a copy of these generated bytes.

## Reusable improvements

- Hold the arena pointer to fire toward the pointer, or hold Space to track the selected target.
- Q / Next target cycles through living enemies. Touch users can hold Fire at target.
- Pointer capture/cancellation, reset, terminal states, focus loss and hidden tabs release held input.
- Leaving the window pauses; returning does not resume automatically.
- Native focused buttons retain keyboard behavior; game key bindings apply to the canvas.
- Ammo updates immediately; unavailable actions are disabled; failed audio permission does not create an unhandled promise.
- Tower health strip, aim guide, remaining-hostile count and player orientation improve feedback.
- Optional `read_arena_status` WebMCP tool exposes only the visible HUD and rejects nonempty input; absent browser support leaves ordinary play unchanged.

- Actual Chrome preview: initial arena rendered; Start entered play; firing reduced ammunition; Next target selected Left Scout; Reload showed RELOADING; Pause disabled firing and held reload state; Resume completed the reload to 30/30; Reset returned ready, Breaker, tower 100%, score 0, ammo 30/30.

- No mobile hardware playtest, audio listening, sustained hold-to-fire browser test, complete browser win/loss playthrough, frame-rate benchmark, or general accessibility certification was performed.
- WebMCP was unavailable in this preview browser; registration/action semantics were tested only with a stub registry in Node.

## Roots and limits

Truth keeps generator checks, JavaScript logic checks and browser observations distinct.
Agency retains explicit start/resume and does not add network calls or automatic play.
Continuity improves the existing generator and carries its original specification/session digests.
Wisdom before speed keeps this a small three-enemy arena, not a claim of arbitrary game creation or polished commercial quality.
