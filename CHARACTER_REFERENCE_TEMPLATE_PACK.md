# Editable Character / Creature Reference Template Pack

`visual.character.core` is a source-first character/creature reference-sheet foundation for games, comics, animation, 3D asset work and design handoff.

## Surfaces

- project / character hub
- turnaround editor
- proportions / measurement editor
- expression sheet editor
- pose / action reference editor
- materials / surfaces editor
- feature / equipment callouts
- scale / variant editor
- source / reference board
- review / export

## Source-first contracts

- `character-source` preserves exact character identity plus source/version.
- `turnaround-view` binds named views to exact identity and camera/view state.
- `proportion-guide` keeps anchors, values, units, source and precision explicit.
- `expression-state` keeps expression identity/source separate from canonical character identity.
- `pose-reference` keeps pose, anchors/skeleton state and provenance explicit.
- `character-material` binds exact body/gear parts to exact material sources.
- `character-callout` binds annotations to exact anatomy/gear/feature targets.
- `scale-reference` keeps reference identity, value, unit and source/assumption state explicit.
- `character-variant` preserves base identity, deltas and status.
- `reference-export-target` keeps required views/dimensions/variants/callouts/provenance visible.

## Truth boundary

A polished reference sheet is not proof that proportions, scale, anatomy, materials or 3D geometry are correct. Presentation views cannot silently redefine the canonical character identity. Approximate/derived measurements remain distinct from exact values. Inspiration/reference material is not treated as canonical character source unless explicitly bound as such.

Deterministic proof can establish responsive layout and structural/editability contracts. It does not prove anatomy quality, modelability, rig compatibility, art quality, physical scale correctness or aesthetic acceptance.
