# Special-effect Hands donor capsule

Portable Universal Creation intake of the first caller-neutral special-effect Hand proof from `mike-axiom-mir/axm-visual-effect-fabric`.

Pinned donor merge commit: `9ce4b0de198aeb5890d8cce58da05a11880348ab` (Visual Effect Fabric PR #3).

## What UC gains

This capsule demonstrates a machine-editable creation loop inside Universal Creation:

`state -> small Hand -> checkpoint -> small Hand -> checkpoint -> ... -> realization`

A caller may edit a saved intermediate checkpoint and resume only the dependent downstream stages instead of rebuilding the whole effect. Caller identity is not part of deterministic result semantics: human UI, AI Agent, Mirror, or ordinary deterministic software can invoke the same graph.

The current proof is an eight-stage electric-storm graph. Canonical topology, energy and layer intent remain editable state; SVG is only a derived preview.

## Boundary

This is a pinned donor capsule, not a declaration that all Universal Creation capabilities must use this exact runtime or schema. It transfers no CANON/permission authority and makes no electrical-physics or aesthetic-quality claim. The standalone `axm-hands-fabric` is the natural long-term home for the general Hand contract and growth; UC is a consumer/composer of compatible Hands.
