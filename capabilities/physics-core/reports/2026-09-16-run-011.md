# UC Physics Growth — Run 011

Date: 2026-09-16
Lane: `chatgpt/hourly-physics-growth-2` / PR #148

## Change

Integrated the Run 010 world-axis translation locks into the established one-donor-step mixed constraint stack rather than chaining the standalone axis-lock wrapper after the composer.

The mixed composer is now v0.4.0 with deterministic family order:

1. translation mounts;
2. exact distance joints;
3. center-distance limits;
4. world-axis translation locks.

Axis-lock position error and locked-axis relative velocity now participate in bounded convergence diagnostics and early-exit decisions. Per-stage axis-lock iteration budgets are independently bounded to 0–32, matching the existing family contract.

## Guarded activity semantics

The constraint activity gate is now v0.2.0 and partitions `axisLocks` alongside the existing three families. `enabled:false` axis locks remain normalized and source/body-reference validated, but are excluded from solving and collision-isolation topology before delegation.

## Component collision isolation

The collision-isolation layer is now v0.3.0. Enabled axis-lock edges participate in deterministic connected-component discovery and can therefore opt into the same temporary negative collision-group isolation during the donor-core collision stage. Orthogonal translation freedom is unchanged; topology participation is not evidence of a second physical constraint axis.

## Evidence added

`axis-lock-integration-selftest.js` proves:

- axis locks participate in the mixed composer with exactly one donor-core integration step;
- the locked axis is stabilized while orthogonal translation remains free;
- an enabled axis-lock edge can form an isolation component and suppress its own donor-core contact only when isolation is requested;
- a disabled axis lock is retained in normalized evidence but excluded from solve residuals and isolation topology;
- the guarded path replays deterministically in one JS runtime.

The existing mixed-composer selftest was upgraded to four-family coverage, including bounded nested axis-lock iteration counts and convergence diagnostics.

## Truth boundary

This does **not** turn axis locks into full slider/prismatic joints. The axis remains world-space and does not rotate with either body. There are still no rotating local anchors, angular inertia, angular limits, motors, hinge, full slider/prismatic, rotational weld or gear semantics.

Collision isolation remains component-wide rather than edge-pair-specific. A connected axis-lock component can suppress internal donor-core contacts when explicitly requested even though orthogonal translation remains physically free.

The imported AXM Physics Core v0.3.1 donor source was not edited by this run. This remains game/prototype physics evidence, not scientific validation.
