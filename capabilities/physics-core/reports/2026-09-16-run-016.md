## Change

Added standalone deterministic fixed-direction translation limits in `uc-direction-limits.js`.

Each limit normalizes one caller-supplied finite non-zero world-space direction and constrains only the scalar projection of relative body translation onto that direction using `minOffset`, `maxOffset`, or both. Translation perpendicular to the direction remains physically free. Range interiors remain slack; position correction activates only outside a bound, and velocity correction activates only when motion at an active boundary points farther outward.

The solver supports inverse-mass sharing, static/kinematic carriers, bounded pre/post stabilization around exactly one donor-core step, disabled-limit inert behavior, deterministic id ordering/replay, explicit `NO_DYNAMIC_MASS` receipts, and preserved donor-core contact-evidence boundaries.
