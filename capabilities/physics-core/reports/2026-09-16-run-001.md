# UC Physics Hourly Growth — Run 001

Date: 2026-09-16 04:22 Europe/Amsterdam

## Goal

Add the first bounded rigid-constraint capability after the initial physics-core graft, while preserving the platform donor source byte-for-byte.

## Change

Added `uc-distance-joints.js`, a deterministic translation-only center-to-center projected distance-joint layer around AXM Physics Core v0.3.1.

The joint layer now provides:

- deterministic joint normalization and ordering;
- bounded position projection toward an explicit target length;
- bounded relative-axis velocity correction;
- static/kinematic anchor support with dynamic followers;
- explicit `NO_DYNAMIC_MASS` receipts when both endpoints are immovable;
- bounded solver iteration controls;
- per-joint before/after distance diagnostics;
- same-runtime checksum evidence through the imported core;
- explicit limitations for missing angular anchors, joint families and collision coupling.

The existing force-based spring path remains separate. It has not been silently renamed or treated as a hard joint.

## Verification added

`distance-joints-selftest.js` covers:

- initial distance-error correction;
- outward impulse/relative-axis velocity locking;
- kinematic-anchor following;
- truthful handling of two immovable endpoints;
- invalid endpoint detection;
- deterministic repeated simulation.

The Physics Core Graft workflow now runs both the original physics capsule selftest and the distance-joint selftest.

## Truth boundary

This run does not add local anchors, rotation, angular inertia, hinge/slider/weld/motor/gear constraints, connected-body collision suppression, deformables, fluids or 3D physics. Joint projection happens before the imported core step, so external forces can create bounded distance error until the next joint solve.

## Coordination

The initial graft PR merged while this run was being written. The hourly task therefore moves to a persistent physics-growth lane for subsequent runs rather than leaving new work attached only to the already-merged graft lane.
