## Change

Added bounded deterministic **single-axis translation locks** in `uc-axis-locks.js`.

Each lock explicitly chooses world-space `x` or `y` and preserves one relative offset between two body centers while leaving the orthogonal translation component free. The layer includes:

- inverse-mass sharing for two dynamic bodies;
- static or kinematic carrier support;
- bounded pre-core position/velocity projection;
- bounded post-core position/velocity stabilization;
- explicit `NO_DYNAMIC_MASS` receipts for immovable pairs;
- disabled-lock inert behavior inside the standalone solver;
- deterministic id ordering and replay checksum evidence;
- separate donor-core collision-stage world/evidence before post stabilization.

The capability is exported through the physics capsule and registered as `AXM-CAP-PHYSICS-AXIS-LOCKS`.

## Why this is bounded

This is intentionally **not called a slider or prismatic joint**. A full slider/prismatic joint would require additional local-axis / rotating-anchor and angular semantics that do not exist in the preserved translation-only stack.

Axis locks are standalone in Run 010. They are **not yet inserted into the mixed constraint composer, activity gate, or component collision-isolation topology**. Chaining the standalone `step` wrapper with the existing composer would advance donor physics twice, so mixed-family integration is deferred to an explicit later gate instead of being implied.
