## Change

Run 008 closes the Run 007 single-step composition gap for **distance limits**.

`uc-constraint-composer.js` now treats distance limits as a third deterministic family:

1. translation mounts;
2. exact distance joints;
3. distance limits.

All three families share exactly one preserved donor-core collision/integration step. Distance limits receive bounded pre/post position and velocity iteration budgets and participate in the existing convergence-aware family-pass system.

Distance-limit convergence is intentionally one-sided:

- position residual is nonzero only outside the configured min/max range;
- velocity residual is nonzero only at an active boundary while motion points outward through that boundary;
- motion inside a slack range does **not** become an exact-joint residual.

`uc-constraint-collision-isolation.js` now also includes distance-limit edges when constructing deterministic connected components. A distance-limit-only assembly can therefore receive the same temporary negative collision-group isolation as mount/joint assemblies.

## Truth boundary

Collision-isolation topology and physical constraint activity are deliberately separate facts. A configured distance-limit edge joins two bodies into one isolation component even while its physical range is slack. That means self-collision can be suppressed for the connected component without pretending the limit is currently transmitting tension/compression.
