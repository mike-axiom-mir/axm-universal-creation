## Integration audit repair

The integration audit found one correctness defect before merge: the point-to-segment helper originally treated every edge whose squared length was at most `Number.EPSILON` as a zero-length point. A real represented finite edge can be shorter than `sqrt(Number.EPSILON)` and still change the radial lower bound by more than the contradiction tolerance. That shortcut could therefore manufacture a false local conflict.

The branch now collapses only exactly zero represented edge length and adds a regression where a `1e-8`-wide feasible edge, offset by `1e-10`, must remain compatible with a `2e-9` radial maximum. The same regression is exercised through the stronger preflight, not only the helper.
