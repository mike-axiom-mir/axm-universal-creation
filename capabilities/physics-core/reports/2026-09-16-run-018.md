## Bounded improvement

Add `uc-constraint-preflight.js`, a deterministic advisory correctness pass for constraints that can be reduced to the same exact normalized 1D translation projection.

The preflight reuses existing normalizers and intersects enabled intervals from translation mounts (x/y exact offsets), axis locks, axis limits, fixed-direction locks and fixed-direction limits. Body-order reversal and direction-sign reversal are canonicalized before grouping. A conflict is reported only when constraints on the same exact normalized projection have an empty interval intersection beyond the configured bounded tolerance.

Disabled analyzed constraints are still validated for body/source integrity but are excluded from intersections. Distance joints and distance limits are counted and reported as unsupported by this v0.1 local proof rather than being silently classified.

## Truth boundary

This is a conservative local preflight, not a global constraint solver or proof of satisfiability, convergence, stability, production readiness or scientific validity. Near-parallel but non-identical directions are deliberately kept separate. The pass is advisory and does not mutate world state, solver order, collision behavior or constraints.
