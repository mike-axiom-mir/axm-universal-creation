## Bounded improvement

The finite two-projection radial-envelope helper now skips redundant edge-distance work for the general inverse-basis path when both signed projection intervals contain zero. Because an invertible linear basis maps projection `(0, 0)` exactly to world-space displacement `(0, 0)`, the feasible parallelogram necessarily contains the origin and its radial minimum is exactly zero. In that case there is no need to project the origin onto all four parallelogram edges.

This is a structural performance improvement only. The helper still reconstructs the four finite corners and evaluates their norms to obtain the radial maximum. Tolerance-eligible near-orthogonal direction pairs remain on the established inverse-basis path; exact orthonormal pairs retain the stricter Run 034 projection-rectangle fast path.

The receipt now exposes `originInsideProjectionRectangle`. The general-path `distanceMethod` is `inverse-basis-parallelogram-origin-contained` when the zero projection is feasible, and `distanceWork.edgeDistanceEvaluations` is then `0` while `cornerNormEvaluations` remains `4`.
