## Change

Added standalone deterministic **world-axis translation limits** in `uc-axis-limits.js`.

A limit constrains one caller-selected world-space `x` or `y` relative offset with `minOffset`, `maxOffset`, or both. Unlike an exact axis lock, motion inside the permitted interval remains slack. Position projection activates only outside the interval; velocity correction activates only when motion at a boundary points farther outward.

Supported bounded behaviors include:

- min-only and max-only one-sided stops;
- finite slack min/max ranges;
- equal min/max fixed world-axis offsets;
- inverse-mass correction sharing for two dynamic bodies;
- static/kinematic endpoints through the existing donor body semantics;
- disabled limits remaining inert in the standalone solver;
- pre-core projection plus post-core stabilization with 0–32 iteration bounds;
- explicit `NO_DYNAMIC_MASS` receipts when a violated range cannot move either body;
- deterministic normalization by id and same-runtime replay evidence.

The orthogonal axis remains intentionally unconstrained.
