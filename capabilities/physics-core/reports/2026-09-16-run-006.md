## Change

Added optional deterministic **constraint-component collision isolation** around the existing mixed constraint composer.

The composer already allowed translation mounts and center-to-center distance joints to share one donor-core integration step, but constrained bodies could still collide with one another unless callers manually authored collision filters. This run adds an explicit assembly-oriented layer:

1. discover connected components from normalized translation mounts and distance joints;
2. order components deterministically by body id;
3. for eligible components whose bodies all retain caller `collision.group === 0`, allocate an unused temporary negative collision-group id;
4. execute the existing composer and exactly one preserved donor-core collision/integration step with that temporary component group active;
5. preserve the actual donor-core collision-stage world as evidence;
6. restore every caller collision group on the returned world and refresh final diagnostics/checksum.

## Truth boundary

This is **component-wide isolation**, not direct-edge pair suppression. If A is constrained to B and B to C, all three share the temporary negative group and A/B/C do not collide with one another during that donor-core collision stage.

A component containing any nonzero caller collision group is skipped with `EXISTING_GROUP_SEMANTICS`; the wrapper does not silently override caller-authored group behavior. Temporary ids are selected from negative groups unused anywhere in the caller world.

Still not implemented or claimed:

- pair-specific connected-body collision suppression independent of connected components;
- automatic rewriting of existing nonzero collision-group semantics;
- angular inertia or rotating local anchors;
- hinge, slider, rotational weld, motor or gear constraints;
- deformables, fluids or 3D physics;
- scientific validation.
