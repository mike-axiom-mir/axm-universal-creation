## Change

Added deterministic translation-only **distance limits** as a separate bounded constraint capability:

- `maxLength` only: rope/tether behavior that allows slack but blocks overstretch;
- `minLength` only: separation/strut behavior that blocks over-compression;
- `minLength` + `maxLength`: a slack allowed range;
- equal minimum and maximum: fixed center-distance behavior through the same boundary solver.

The solver keeps allowed range interiors unconstrained. Position projection activates only outside a configured boundary, and relative-axis velocity is blocked only when motion would continue through an active minimum or maximum boundary. Dynamic bodies share correction through inverse mass; static and kinematic bodies remain immovable in the constraint solve.

As with the existing additive constraint work, the capability executes bounded pre-core projection, exactly one preserved donor-core collision/integration step, and bounded post-core stabilization while retaining the actual donor collision-stage world as evidence.

## Truth boundary

This is not a generalized rope, cable or rigid-body joint model. It constrains body centers only and does not model angular inertia, rotating anchors, rope mass, sag, elasticity, bend dynamics or segment collision.

The new family is intentionally **not yet integrated** into `uc-constraint-composer.js` or `uc-constraint-collision-isolation.js`. Callers that need distance limits mixed with mounts/distance joints in one physical frame should wait for explicit composer integration rather than chaining independent step wrappers and accidentally advancing donor physics more than once.

Still not claimed:

- local anchors or angular response;
- hinge, slider, rotational weld, motor or gear constraints;
- deformables, fluids or 3D physics;
- cross-JavaScript-engine deterministic equivalence;
- scientific validation.
