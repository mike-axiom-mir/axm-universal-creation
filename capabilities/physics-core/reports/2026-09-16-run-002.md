## Change

Upgraded the additive translation-only distance-joint layer from v0.1.0 to v0.2.0 with bounded **post-core stabilization**.

Run 001 projected joint position and relative-axis velocity before the preserved AXM Physics Core step. Gravity, forces or other core-stage integration could then reintroduce distance error before the next frame. Run 002 keeps that pre-solve, lets the unchanged v0.3.1 donor core own collision/integration, then performs configurable post-core position and velocity passes on the UC joint layer.

Default second-stage bounds:

- post position iterations: 4
- post velocity iterations: 2
- caller may explicitly set either to 0
- global iteration bound remains 0–32 per stage

## Evidence / diagnostics added

The step result now separates:

1. initial joint state;
2. state after pre-core solve;
3. state after core integration;
4. stabilized final state.

It records both `maxErrorAfterCoreStep` and `maxErrorAfterStabilization`, plus post-stage receipts. The untouched core-stage world is retained at `core.worldBeforePostConstraintStabilization`.

Final diagnostics are refreshed so the returned checksum describes the stabilized final state.

## Truth boundary

Post-core projection can move bodies after the core generated collision/contact evidence. The implementation therefore does **not** silently pretend those events or contact geometry were generated from the later stabilized positions.

The returned diagnostics explicitly label the basis as:

`CORE_STAGE_BEFORE_POST_CONSTRAINT_STABILIZATION`

Still not implemented or claimed:

- local anchors or angular response;
- angular inertia/rotation;
- hinge, slider, weld, motor or gear joints;
- connected-body collision suppression;
- deformables, fluids or 3D physics;
- scientific validation.

## Regression added

`distance-joints-selftest.js` now creates a static-anchor + dynamic-body case under gravity and compares post stabilization disabled versus enabled. The test requires measurable distance drift without the second stage and near-zero bounded distance error with stabilization, while also checking evidence separation and final-checksum consistency.

Verification command:

`node capabilities/physics-core/distance-joints-selftest.js`
