# Editable Infographic / Diagram Template Pack

`visual.diagram.core` gives Universal Creation a source-first foundation for architecture maps, flowcharts, causal/relationship diagrams, explainers, evidence maps and infographics.

The central rule is semantic truth: **visual proximity never becomes an undeclared relationship**. Nodes, edges, data, claims, annotations and evidence remain distinct editable state.

## Product surfaces

The product contains ten responsive screens:

- project / diagram hub;
- canvas editor;
- node editor;
- relationship editor;
- evidence / data binding editor;
- annotation / callout editor;
- legend / semantic style editor;
- layout variants;
- review / truth check;
- export matrix.

## Semantic and evidence contracts

- `diagram-node` — exact entity/concept/state identity;
- `relationship-edge` — exact from/to endpoints, relation type and direction;
- `evidence-reference` — source plus observed/derived/claimed/missing status;
- `data-field` — value, unit, source and period/freshness remain explicit;
- `annotation-pin` — exact target reference;
- `legend-entry` — semantics cannot depend on color alone;
- `group-boundary` — membership/criteria remain explicit;
- `layout-guide` — layout aids cannot change semantic relationships;
- `callout-card` — content and evidence status stay separate;
- `diagram-export-target` — output requirements stay explicit.

## Layout variation

Alternate routing, grouping and aspect/layout choices may improve readability, but they cannot add/remove/retype semantic relationships. `math_hooks` expose spacing and label-clearance ranges for the separate mathematics lane.

## Truth boundary

This pack proves deterministic structure and semantic/evidence contracts only. It does not prove that a relationship is scientifically or factually true, that evidence is sufficient, that causal interpretation is justified, that numerical data is correct, or that a finished diagram is aesthetically effective.

Consuming products must provide real sources/evidence. Missing, disputed, derived and claimed state stays visible rather than being converted into confident-looking graphics.
