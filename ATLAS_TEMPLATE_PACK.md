# Editable World-Map / Lore-Atlas Template Pack

`visual.atlas.core` gives Universal Creation a source-first foundation for fictional or evidence-backed world maps, lore atlases, state maps and chronology overlays.

The core rule is spatial truth: **missing coordinates, routes, borders or place state stay unknown rather than being invented to make the map look complete.**

## Product surfaces

The product contains ten responsive screens:

- project / atlas hub;
- world-map editor;
- region / boundary editor;
- route / path editor;
- POI / lore-reference editor;
- layer editor;
- timeline / state-overlay editor;
- coordinate / spatial-source editor;
- review / comparison;
- export matrix.

## Spatial and narrative contracts

- `map-region` — exact geometry/source/status;
- `route-path` — explicit endpoints plus known/planned/blocked/unknown status;
- `poi-marker` — exact identity and location source/status;
- `map-layer` — named independent layer with provenance;
- `time-slice` — explicit period plus current/historical/projected/unknown status;
- `lore-reference` — exact target plus source/status;
- `boundary-line` — explicit boundary type, source and uncertainty;
- `map-coordinate` — coordinate system, source and precision remain explicit;
- `state-overlay` — source and time slice remain bound;
- `atlas-export-target` — extent/layers/labels/provenance requirements remain visible.

## Truth boundary

This pack proves deterministic structure and spatial/editability contracts only. It does not prove that a coordinate, border, route, geopolitical claim, historical state or lore claim is correct. Projected state cannot be presented as observed state. Approximate or derived coordinates stay distinguishable from exact coordinates.

Consuming products must provide real source state. Derived exports never replace richer editable atlas source.
